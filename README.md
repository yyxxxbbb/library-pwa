# 📚 스마트 도서관 (library-pwa)

이 문서는 프론트엔드(UI)부터 백엔드(Firebase) 통신까지 완벽하게 분리된 본 프로젝트의 핵심 파일 구조와 역할을 설명합니다. 
새로운 팀원이 합류하거나 특정 기능을 수정/유지보수할 때 아래 표를 참고하여 파일 위치를 빠르게 파악하세요!

<br/>

## 📁 주요 파일 역할 총정리

| 분류 | 파일명 | 주요 역할 및 기능 |
| :--- | :--- | :--- |
| 📱 **전체 화면 (Pages)** | `App.jsx` | **앱의 최상위 뼈대**. 화면 이동(라우팅), 알림 팝업 제어, 전체 레이아웃 유지 |
| | `Auth.jsx` | **인증 화면**. 로그인, 회원가입, 비밀번호 찾기 로직 및 UI |
| | `AdminDashboard.jsx` | **관리자 상황실**. 시험기간 통제 설정, 이용 통계 차트, 전체 회원 관리, 신고 접수 내역 및 패널티 부여 |
| | `MyPage.jsx` | **마이페이지**. 일반 사용자의 누적 패널티 확인 및 과거 좌석 이용 내역(영수증) 조회 |
| | `Scanner.jsx` | **관리자용 스캐너**. 스마트폰 카메라로 학생의 QR 코드를 인식하여 즉시 입실 처리 |
| 🧩 **화면 조각 (Components)**| `FloorMap.jsx` | **좌석 배치도 UI**. 층별로 좌석을 그리고, 상태(예약, 사용중 등)에 따라 실시간으로 색상 및 정보 표시 |
| | `SeatModal.jsx` | **좌석 상세 팝업**. 배치도에서 좌석을 눌렀을 때 하단에서 올라오는 예약, 취소, 신고 메뉴 창 |
| | `QRCodeGen.jsx` | **QR 생성기**. 입구 스캐너 인증을 위해 15초마다 갱신되는 학생 개인용 QR 코드 렌더링 |
| 🪝 **백그라운드 (Hooks)** | `useLibraryData.js` | **데이터 공급기**. DB에서 실시간 좌석 상태와 유저 정보를 읽어와 앱 전체에 전달 |
| | `useLibrarySystem.js` | **시스템 감시자**. 이용 시간 만료 전/후 경고 알림 띄우기, 통제 기간 초과 시 자동 해제 로직 |
| | `useUserSession.js` | **보안 및 접속 관리**. 중복 로그인(다른 기기 접속) 방지, 30분 미활동 시 자동 로그아웃 |
| ⚙️ **데이터 통신 (Service)** | `libraryService.js` | **핵심 비즈니스 로직**. 예약, 취소, 퇴실 액션 시 연관된 DB 데이터들을 한 번에 조작 |
| | `bookingService.js` | **QR 인증 로직**. 카메라 스캐너가 QR을 읽었을 때 해당 학생의 예약 좌석을 찾아 '사용 중'으로 변경 |
| | `seatApi.js` | **좌석 DB 통신**. 좌석 상태 업데이트 및 퇴실 시 '실제 사용 시간'을 계산하는 기능 |
| | `authApi.js` | **인증 통신**. 파이어베이스(Firebase) Auth와 통신하여 로그인/로그아웃 처리 |
| | `logger.js` | **기록(Log) 작성기**. 도서관에서 일어나는 모든 이벤트(예약, 퇴실, 신고, 제재 등)를 DB에 히스토리로 저장 |
